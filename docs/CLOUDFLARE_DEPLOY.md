# Cloudflare Pages 测试版部署

此版本默认从域名根路径部署，暂用“性格探索”作为网站名称。问卷和计分逻辑沿用原项目，未进行心理测量有效性验证。

## 控制台配置

1. 在 Cloudflare 控制台的 Workers & Pages 中创建 **Pages** 项目，选择导入 Git 仓库。
2. 连接 GitHub，并选择 `2898649797l-ai/mbti-lab`。仅授权需要的仓库即可。
3. 按下面的配置部署。

| 配置项 | 值 |
| --- | --- |
| 生产分支 | `main`（合并部署修改后） |
| 构建命令 | `npm run build` |
| 构建输出目录 | `dist` |
| 根目录 | 默认，项目位于仓库根目录 |
| Node 版本 | `24`，仓库包含 `.node-version`；也可设置 `NODE_VERSION=24` |

无需数据库、API Key 或额外的后端变量。部署后通过控制台返回的 `*.pages.dev` 地址测试。项目名影响这个地址，但不要求与正式品牌名一致。

本地检查：

```sh
npm ci
npm test -- --run
npm run build
npm run preview
```

## 分享与存储

- 分享文案、复制链接和海报二维码使用当前访问域名及 Vite base。绑定独立域名后无需在源码中填写网址。
- 默认分享与二维码指向首页；用户主动创建快照并选择二维码目标后，链接通过fragment携带所选择的结果。无原始答案、结果上传API或数据库；快照对持有链接者可见且不能撤回。
- 测评结果保存在访客浏览器的 sessionStorage / localStorage 中，清除网站数据后无法恢复。此版本没有上传测评结果的接口。
- 点击分享面板中的保存图片后生成海报预览，再点击下载链接或长按图片保存。若生成失败，会显示重试提示。
- 已移除上游统计脚本。托管平台仍可能处理必要的访问日志；以后新增统计服务时，应同步调整页面隐私说明。
- 保留 Hash Router；当前版本还没有静态化人格详情页或完整 SEO 改造。
- manifest 和图标支持添加到主屏幕；当前源码没有 service worker，不能据此承诺离线使用。
- 原 GitHub Pages 工作流单独以 `/mbti-lab/` 构建，Cloudflare 使用根路径。

## 测试版验收

- 手机打开首页，完成 60 题测试，并抽测 93 题版本。
- 返回上一题、生成结果、刷新结果页、查看上次结果。
- 切换中文和英文，保存海报并检查文字和二维码。
- 用另一设备扫描二维码，确认进入你自己的站点。
- 在微信内置浏览器、iOS Safari 和安卓浏览器中实测。
- 分别用中国移动、电信、联通网络测试打开速度和稳定性。
